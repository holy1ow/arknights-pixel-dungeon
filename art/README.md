# 当前实装美术编辑入口

`manifest.json` 记录 176 项逻辑素材及 6 份仅供染色参考的源图，按 SHA-256 引用原始可编辑文件。当前公开版为 0.0.4。实际像素、源文件与动画时长均来自已确认交付，不重新生成美术。

- `art/source/`：真实 LibreSprite/Aseprite 源；`sourceLayers` 如实记录，赫拉格新增源均为单层，不表示语义分层。
- `art/animations/amiya/`、`art/animations/hellagur/`：真实动作索引、帧率及效果时长；赫拉格转职还提供 `animationSource`。
- `art/exports/`：头像、子职业图标单格 PNG；运行图集位于 `core/src/main/assets/`。
- `art/provenance/`：批准来源、开发路径与散列映射；历史制作状态保持，当前实装状态以 manifest 为准。

赫拉格：基础不变；不屈 v14 B、连斩 v16 A，36×28 画布、21 槽、7 护甲行，身体参考 `(10,3,16,21)`，脚底 `(18,24)`，透明边距 `(8,3,8,4)`，世界框 20×21。怀表 E02-C、“热的雪”E03-D；不屈头像 v20 D、连斩头像 v22 F。其余选版见 manifest 的 selection。攻击和施法继续共用原接口。66 项迁入源经过原生导出，与安装 PNG 的 RGBA 像素相等。

阿米娅继续 frozen：24×24 画布、16×21 身体框、原批准像素与动画不变。共享头像图集只替换赫拉格槽 4/5，阿米娅和其他角色单格不变。

全角色美术尚未全部最终验收。历史 v1–v22、旧源和未选稿保留在 v0.0.4 Release 的美术归档；既有阿米娅封版历史继续链接原归档，不重复上传。旧记录中的“待审/未安装”只描述当时状态。历史 V6 效果库的同名 sheet.png 有扁平化记录，本版从原 v6 各效果目录读取对应导出，并核对原 SHA-256 与原生源；未覆盖历史文件。

修改后须同步源、导出及清单，并运行 `python scripts/verify_assets.py [app-image]`（需要 Pillow）。开发工程与独立公开工程不能整目录互相覆盖。
