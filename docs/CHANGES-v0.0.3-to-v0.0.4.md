# v0.0.3 → v0.0.4 对比

对比基线为已公开标签 **v0.0.3**，提交 `501d9ecfa57c0c96ecb54bc405fccecd26999a51`；本次在原独立公开仓库上增量迁入，没有用开发工程覆盖公开工程。共同上游仍为 Shattered Pixel Dungeon 4.0.2。本版继续是开发预发布，特色机制未加入。

| 项目 | v0.0.3 | v0.0.4 |
| --- | --- | --- |
| 玩家入口 | 六位换皮角色，赫拉格默认解锁 | 保持六位、相同解锁条件与教程 |
| 赫拉格基础形态 | 原已确认图集 | 字节保持 |
| 不屈 / 连斩 | 较早转职图集，20×21 画布 | 不屈 B v14、连斩 A v16 全动作；36×28 透明画布，世界框仍20×21，身体宽仍16 |
| 转职 / 护甲进阶道具 | 原面具与王冠外观 | 确认的旧日怀表 E02-C、“热的雪” E03-D；原消耗与选择机制 |
| 转职头像 | 较早头像 | 不屈 v20 D、连斩 v22 F；仅共享头像槽4/5替换 |
| 赫拉格图标与效果 | 较早共享图形 | 27枚天赋混选、4枚能力/行动图标、确认装备、15组效果、6种状态各大小图标 |

| 阿米娅 | 2026-10-20封版 | 保留封版素材、源与作用条件 |

| 显示与线程 | 旧转职画布；攻击外层精灵锁 | 边距/脚底/HUD适配；效果插入移出外层锁，原CharSprite动画同步和战斗回调保持 |
| 美术清单 | 114项逻辑素材＋6份染色参考 | 176项＋相同6份参考；66项新增或更新的源原生导出通过 |
| 发行版本 | 游戏/构建/EXE 0.0.3，标签v0.0.3 | 游戏/构建/EXE 0.0.4，标签v0.0.4 |

| 依赖及许可 | JSON-java20240303、Java17及既有依赖 | 保持，不重复上传依赖源码档 |

运行资源新增62个赫拉格独立PNG，更新两个转职图集和共享头像图集中的两个赫拉格单格；四份语言文件仅追加对应键。共选择性迁入88个代码/资源文件，另更新公开版本显示。105项非赫拉格美术清单记录保持，唯一容器元数据变化是共享头像图集整体哈希；各其他角色单格像素不变。开发工作区23273个保护文件逐一比对保持。

验证覆盖详见 [联合验收](QA-0.0.4.md)：六角色两转职及随机选择、两主角18条桌面/窄屏检查点路线、v0.0.3→v0.0.4实际EXE冷继续、进阶、保存重载、跨层、8组身份/形态96次攻击与法杖消耗、新用户首次开局。测试夹具提供部分物品、楼层与目标，不冒称自然完整游玩。

运行包仅保留游戏、Windows运行依赖、Java、许可与启动说明。当前可编辑源在仓库；赫拉格v1–v22旧稿/未选稿在 `03-Art-History.zip`，验证资料在 `04-Tests.zip` / `05-Tests-2.zip` / `05-Tests-2.zip`。历史测试档和旧运行包在本地保留，网络验证归档提供证据与保留索引，不把测试存档分发给玩家。既有阿米娅历史继续使用[原封版归档](https://github.com/holy1ow/arknights-pixel-dungeon/releases/tag/amiya-reskin-frozen-20261020-public)，旧标签、旧发布及旧附件不覆盖。
