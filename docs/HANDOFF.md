## 编辑入口与历史

开发工程正式入口为 `art-source/library/current/amiya/`。公开副本由 `art/manifest.json` 映射到 `art/source/`、`art/animations/amiya/` 和实际运行资源，批准记录和路径/散列映射在 `art/provenance/`。制作 manifest 中历史待审/未安装字样保持原样，以较新批准安装侧记录和本版验证为准。

`core/src/main/assets/` 是运行资源；`core/src/main/java`、`SPD-classes/src`、`desktop/src`、`services` 是代码；`docs` 是说明和精简预览；各 `build` 和 `.gradle` 为可再生输出。公开工程是独立 Git 仓库，不可当缓存清理或被开发工程整目录覆盖。
