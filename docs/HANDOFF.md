# 0.0.1 接续说明

维护者 holy1ow。发布项目为 `holy1ow/arknights-pixel-dungeon`，首个标签 `v0.0.1`。该精简桌面源码从本地共同开发基线 `981b647dbb8978a21e3ea03d51689631f4354863` 导出；上游为 Shattered Pixel Dungeon v4.0.2 / `57a4e06a4caf162446d1c28caa7983f0493fecf0`。

当前仍是共同开发快照。全角色美术尚未全部验收；医疗阿米娅尚未选型；角色特色机制尚未进入本轮。未来从验收后的共同美术基线拆分“保留原版机制的换皮版”和“角色特色机制版”，本轮未创建特色机制分支。

## 编辑入口

| 路径 | 职责 |
| --- | --- |
| `core/src/main/java`、`SPD-classes/src` | 游戏代码及框架 |
| `core/src/main/assets` | 游戏实际读取、构建打包的资源 |
| `art/manifest.json`、`art/source` | 当前实装美术映射和可编辑源，按散列去重 |
| `art/exports` | 头像、图标图集的单格导出 |
| `desktop/src`、`desktop/build.gradle` | 桌面启动器、验证程序、打包配置 |
| `services` | 离线新闻、更新适配，避免请求上游项目服务 |
| `docs` | 发布说明、验证结果及 README 预览 |
| `desktop/build`、各模块 `build`、`.gradle` | 可重新生成的输出和缓存，不纳入 Git |

## 约束与接续要点

- 公开选角池由 `HeroClass.selectableClasses()` 定义，只含六名干员；原六职业枚举留作机制和兼容标识。`asSelectable()` 将旧默认标识映射到对应干员。不要删除机制枚举或改变 `gameplayClasses()` 来减少界面角色。
- 随机选角也使用六名干员池。职业解锁要求未改；正式版初始只有赫拉格可用。不要将 QA 里使用的临时进度带进发行包。
- 公共版本号为 0.0.1；内部版本代码保留 922 以避免触发错误迁移。应用名及存档命名空间独立于上游。
- core 中的 TrainerBridge 是固定禁用的空实现，仅为已有调用保留兼容；没有启用版 trainer、工具界面或测试后门。
- 阿米娅三形态运行动画仍为同一基础外观。持剑、蓝光托手、白杖候选稿和暂停记录留在原共同开发工作区及其开发保全包，未放进公开仓库、未安装。需要后续工作时回到完整工作区读取暂停记录，不凭公开仓库推断候选已验收。
- 纯换皮发行仓库没有候选稿、个人存档、完整历史工程、原 Git 历史或 Android/iOS 工程。它能单独构建桌面版，但不能代替完整开发保全包恢复制作历史。
- JSON 库改为公有领域的 20240303 版本；源文件逐项保留原版权头并对修改的 Java 文件添加改编日期。发行时继续携带 GPL、署名和第三方源码附件。

构建与验证入口见 [RELEASE-0.0.1.md](RELEASE-0.0.1.md)。今后的变更需同步源、导出、运行资源散列；不要只替换 README 图片或旧 Release 压缩包。
